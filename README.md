# carolinedanslesnuages.github.io

Site des projets open source de Carolinedanslesnuages, généré avec [Docpress](https://github.com/this-is-tobi/docpress).

## Ajouter un projet

1. Le dépôt doit être **public**, avec une description GitHub (elle s'affiche sur la page d'accueil).
2. Ajouter son nom dans `reposFilter` de [`docpress.config.json`](./docpress.config.json).
3. Pousser sur `main` : le site se reconstruit et se déploie tout seul.

La documentation de chaque projet vient de son dossier `docs/` (fichiers préfixés `01-`, `02-`… pour l'ordre) ou, à défaut, de son `README.md`.
